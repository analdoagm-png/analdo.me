# Claude Project Entry

Project guidance has been consolidated into `AGENTS.md`, and the design system lives in `DESIGN.md`.

When working on this project:

- Read `AGENTS.md` for implementation, framework, accessibility, verification, and workflow rules.
- Read `DESIGN.md` for tokens, typography, shared component styling, motion, and responsive design conventions.
- Keep both files updated when project behavior or the visual system changes.

`FRONTEND.md` is also in the repo root but is **not** guidance for this
project: it is a portable backend-handoff playbook describing directories and
artifacts (`src/features/`, `contracts/`, MSW fixtures) that do not exist
here. Do not follow its §6 agent instructions in this repo — `AGENTS.md` wins.
